Requirement Gathering

กรอกข้อมูลเพื่อเก็บความต้องการระบบงาน (18 ข้อ)

• อธิบายฟังก์ชันที่ต้องการ และเหตุผล / ปัญหาที่ต้องการแก้ไข
• ต้องการให้ระบบช่วยเรื่องอะไร?
• ปัจจุบันมีปัญหาอะไร?
• ต้องการให้ระบบช่วยลดงานส่วนไหน?
กรุณาระบุข้อมูลในช่องนี้
• ระบุเอกสารที่เกี่ยวข้องกับกระบวนการนี้ทั้งหมด
• เอกสารที่ใช้เริ่มต้น
• เอกสารที่เกี่ยวข้องระหว่างกระบวนการ
• เอกสารที่ต้องสร้างต่อ
• เอกสารที่ต้องนำข้อมูลมาใช้ร่วมกัน
กรุณาระบุข้อมูลในช่องนี้
• ระบุขั้นตอนการทำงานปัจจุบันตั้งแต่เริ่มต้นจนจบ พร้อมระบุ:
• ขั้นตอนไหนทำในระบบ
• ขั้นตอนไหนทำ Manual
• ขั้นตอนไหนใช้ Excel / Email / Line
• ปัญหาที่พบในแต่ละขั้นตอน
กรุณาระบุข้อมูลในช่องนี้
• ระบุขั้นตอนการทำงานที่ต้องการหลังพัฒนาเสร็จ:
• เริ่มจากอะไร → ใครทำ → ระบบทำอะไร → ได้ผลลัพธ์อะไร
กรุณาระบุข้อมูลในช่องนี้
• ระบุเงื่อนไขที่เกี่ยวข้อง เช่น:
• จำนวนเงิน / จำนวนสินค้า / วันที่ / สถานะเอกสาร / ประเภทสินค้า / ลูกค้า / Supplier / สาขา / บริษัท / ผู้ใช้งาน / เงื่อนไขอื่น ๆ
กรุณาระบุข้อมูลในช่องนี้
• ควรตกลง State / สถานะของเอกสารให้จบตั้งแต่ตอนเก็บ Requirement และระบุ:
• เอกสารเริ่มต้นด้วยสถานะอะไร / มีสถานะอะไรบ้าง / ใครเป็นคนเปลี่ยนสถานะ / แต่ละสถานะทำอะไรได้ / ใครเป็นผู้อนุมัติ / ถ้าไม่อนุมัติ หรือ Reject ต้องกลับไปสถานะไหน / เมื่อแก้ไขแล้วต้องส่งอนุมัติใหม่หรือไม่
• Concern: ขอให้ตกลง Workflow และสถานะร่วมกันให้ชัดเจนก่อนเริ่มพัฒนา
กรุณาระบุข้อมูลในช่องนี้
• ระบุว่าแต่ละฝ่าย / แต่ละตำแหน่งสามารถทำอะไรกับเอกสารได้:
• ดู / สร้าง / แก้ไข / ส่งอนุมัติ / อนุมัติ / ยกเลิก / พิมพ์ / ดาวน์โหลด / รวมถึง ใครเห็น หรือไม่เห็นข้อมูลบางส่วน
กรุณาระบุข้อมูลในช่องนี้
• ถ้ามี ให้ระบุ:
• ใครเป็นผู้ขอ / ใครอนุมัติ / มีผู้อนุมัติกี่ระดับ / อนุมัติตามเงื่อนไขอะไร / ถ้าไม่อนุมัติทำอย่างไร / ถ้าแก้ไขข้อมูลหลังไม่อนุมัติ ต้องส่งอนุมัติใหม่หรือไม่
กรุณาระบุข้อมูลในช่องนี้
• ระบุ: แจ้งใคร / แจ้งเมื่อเกิดเหตุการณ์อะไร / ต้องการแจ้งผ่าน Email หรือกระดิ่งในระบบ / ต้องแจ้งทั้ง Email และกระดิ่งหรือไม่
• ตัวอย่าง: เมื่อมีเอกสารรออนุมัติ → แจ้งผู้อนุมัติผ่านกระดิ่งในระบบ
กรุณาระบุข้อมูลในช่องนี้
• พิจารณาว่าต้องส่งหรือรับข้อมูลจากระบบอื่นหรือไม่ เช่น LINE, ระบบชำระเงิน, ระบบภายนอกของบริษัท, ระบบอื่นที่ใช้งานอยู่
• ระบุ: ต้องการส่งข้อมูลอะไร / ต้องการรับข้อมูลอะไร / ต้องการให้ระบบทำงานอัตโนมัติเมื่อใด
• Concern: หากเชื่อมโยงได้ ควรพิจารณาตั้งแต่ต้นเพื่อลดขั้นตอนการกรอกข้อมูลซ้ำซ้อน
กรุณาระบุข้อมูลในช่องนี้
ใช้เฉพาะข้อมูลใหม่
เริ่มต้นบันทึกข้อมูลใหม่เมื่อระบบเริ่มใช้งาน ไม่นำเข้าประวัติข้อมูลเก่า
ใช้ข้อมูลเก่าด้วย
ต้องการโอนย้าย หรือนำประวัติข้อมูลเก่าเข้าระบบใหม่ด้วย
• ระบุว่าฟังก์ชันใหม่ต้องใช้กับข้อมูลเก่าหรือไม่:
• ต้องนำข้อมูลเก่ามาแสดง หรือต้องปรับปรุงข้อมูลเก่าให้เข้ากับรูปแบบใหม่ด้วยหรือไม่
• พิจารณาว่าต้องเพิ่ม / แก้ไขข้อมูลหลักหรือไม่ เช่น ลูกค้า, Supplier, สินค้า, คลังสินค้า, พนักงาน, สาขา, บริษัท, บัญชี
• ระบุด้วยว่า มีข้อมูลเดิมอะไรที่ควรปรับปรุงก่อนเริ่มใช้งานหรือไม่
กรุณาระบุข้อมูลในช่องนี้
• ถ้ามี ให้แนบตัวอย่างเดิม และระบุสิ่งที่ต้องการ:
• ข้อมูลที่ต้องเพิ่ม / ข้อมูลที่ต้องแก้ไข / รูปแบบเอกสาร / ขนาดกระดาษ เช่น A4 / A5 / แนวตั้ง / แนวนอน / พิมพ์กี่หน้า / ต้องการรูปแบบเฉพาะหรือไม่
กรุณาระบุข้อมูลในช่องนี้
• ถ้ามี ให้แนบตัวอย่าง Report / Excel และระบุ:
• ต้องการดูข้อมูลอะไร / ค้นหาด้วยอะไร / แสดงข้อมูลอะไรบ้าง / คำนวณตัวเลขอะไร / Export Excel หรือไม่
• Concern กรณี Report ใช้ร่วมหลายฝ่าย: ฝ่ายไหนดูได้ / ดูได้บางส่วน / ไม่ควรเห็น (โดยเฉพาะเรื่อง ราคา / ต้นทุน / กำไร / ยอดเงิน)
กรุณาระบุข้อมูลในช่องนี้
• ระบุ: ชื่อข้อมูล / ต้องกรอกเอง หรือดึงค่า / จำเป็นต้องกรอกไหม / ให้ใครเห็นบ้าง / ให้ใครแก้ไขได้บ้าง
• Concern: หากเป็นข้อมูลเกี่ยวกับเงิน / ราคา / ต้นทุน ควรระบุให้ชัดเจนว่า ฝ่ายไหนเห็นได้ และฝ่ายไหนไม่ควรเห็น
กรุณาระบุข้อมูลในช่องนี้
• ระบุเอกสารที่ต้องแนบ เช่น ใบเสนอราคา / เอกสารอนุมัติ / สัญญา / รูปภาพ
• ระบุ: ใครแนบไฟล์ได้ / ใครสามารถเปิดดูได้ / ใครดาวน์โหลดได้ / ไฟล์บางประเภทเป็นข้อมูลภายในหรือสำคัญหรือไม่
• Concern: หากมีไฟล์สำคัญและไม่ต้องการให้ทุกคนเห็น อาจพิจารณาแยกปุ่มสิทธิ์เข้าถึงเฉพาะเพื่อควบคุม
กรุณาระบุข้อมูลในช่องนี้
• เหตุการณ์พิเศษนอกเหนือจากปกติ เช่น ยกเลิกเอกสาร / คืนสินค้า / ทำบางส่วน / จำนวนเกิน-ไม่ครบ / ข้อมูลซ้ำ-ไม่มี-ไม่ครบ / แก้ไขหลังส่งหรืออนุมัติ / Reject ส่งใหม่ / ผู้รับผิดชอบไม่อยู่ / ระบบอื่นล่ม
• Concern: ควรช่วยกันระบุกรณีที่ "อาจเกิดขึ้นจริง" เพื่อให้ระบบรองรับตั้งแต่แรก
กรุณาระบุข้อมูลในช่องนี้
• เมื่อพัฒนาเสร็จสิ้น ต้องการให้ระบบ: แสดงข้อมูล / บันทึกข้อมูล / สร้างเอกสาร / เปลี่ยนสถานะ / แจ้งเตือนใคร / ส่งข้อมูลไปที่ไหน / แสดง Report หรือ Print Format อย่างไร
กรุณาระบุข้อมูลในช่องนี้
